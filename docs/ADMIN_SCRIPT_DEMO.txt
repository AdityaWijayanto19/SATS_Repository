========================================
  SCRIPT VIDEO DEMO — BAGIAN SUPERADMIN
  Durasi: ±60 detik
========================================

[0:00 - 0:10] TAMPILAN AWAL — DASHBOARD
────────────────────────────────────────
Tunjukkan dashboard superadmin dari atas.
Arahkan ke stat cards.

NARASI:
"Ini adalah dashboard superadmin. Di bagian atas, terlihat
ringkasan sistem secara real-time — total alat, alat aktif,
non-aktif, total pengguna, dan pengguna yang sedang online."

---

[0:10 - 0:25] TABEL PERANGKAT & LOG AKTIVITAS
──────────────────────────────────────────────
Tunjukkan tabel perangkat aktif di kiri, log aktivitas di kanan.

NARASI:
"Di bawah, superadmin bisa memantau perangkat aktif beserta
kondisi pasien dan tim medis yang bertugas. Di sisi kanan,
log aktivitas sistem tercatat secara real-time."

---

[0:25 - 0:40] MENU SIDEBAR — MANAJEMEN
───────────────────────────────────────
Arahkan ke sidebar, tunjukkan satu per satu menu.

NARASI:
"Superadmin juga memiliki akses ke beberapa fitur manajemen.
Manajemen Alat untuk mendaftarkan dan mengelola perangkat IoT.
Manajemen User untuk mengelola akun dokter dan ners.
Rekam Medis untuk melihat, mencari, dan menghapus data
rekam medis pasien."

---

[0:40 - 0:50] FITUR TAMBAHAN
────────────────────────────
Buka halaman Laporan atau Inbox (tunjukkan sekilas).

NARASI:
"Ada juga fitur Laporan untuk export data operasional,
dan Inbox untuk menangani laporan dukungan dari pengguna."

---

[0:50 - 1:00] PENUTUP
─────────────────────
Kembali ke dashboard, tunjukkan data real-time berubah.

NARASI:
"Semua fitur ini memberikan kontrol penuh kepada superadmin
untuk mengelola dan memantau seluruh operasional sistem SATS."

---

========================================
  CATATAN PRODUKSI
========================================

- Pastikan ada minimal 1 device online saat recording
- Reverb harus running agar real-time terlihat
- Resolusi rekomendasi: 1920x1080
- Zoom browser: 100% agar semua stat cards terlihat
- Buka sidebar sebelum recording agar transisi smooth
